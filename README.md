# 🌐 Novo Trinity — Página Inicial Moderna com HTML5, CSS e JavaScript

Este projeto é uma página inicial desenvolvida em **HTML5**, **CSS3** e **JavaScript**, criada para demonstrar um layout moderno com **efeito tecnológico animado sobre o banner principal**.  
O site é totalmente responsivo e foi construído sem frameworks — apenas código puro e organizado.

---

## 🚀 Demonstração
🔗 **Acesse o projeto:**  
https://luizrogeriopx.github.io/novotrinity/

---

## 🛠 Tecnologias Utilizadas

- **HTML5** – Estrutura da página  
- **CSS3** – Estilização, responsividade e organização visual  
- **JavaScript** – Efeito animado de tecnologia aplicado ao banner do topo

## ✨ Funcionalidades

- Layout limpo e profissional

- Seções bem organizadas e responsivas

## 💡 Efeito Tecnológico no Banner

O JavaScript é responsável por gerar o efeito animado no topo, criando uma experiência futurista e dinâmica.
